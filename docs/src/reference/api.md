# API reference (rustdoc)

The internal Rust API documentation is generated by `cargo doc` and embedded alongside this book by `cargo xtask docs`.

- [bootcher-core](../api/bootcher_core/index.html) — library: builders, jobs, pipelines, fleet, hooks
- [bootcher-cli](../api/bootcher_cli/index.html) — CLI binary entry point and command definitions

> These links only resolve in the fully built site (`cargo xtask docs`). `cargo xtask docs-watch` clears its output on every live-reload rebuild, which removes the `api/` directory — use `cargo xtask docs` then open `docs/book/index.html` directly when you need working API links.
